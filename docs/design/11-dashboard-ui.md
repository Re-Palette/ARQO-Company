# 11. Dashboard UI 設計

添付デザインを最優先リファレンスとし、世界観（ダークネイビー × 夜明けの都市 × ネオンアクセント）と情報密度を継承しつつ、**毎日使う経営ダッシュボード**として整理する。

## 11.1 参考デザインからの改善点

| # | 参考画像 | 本設計での進化 | 理由 |
|---|---|---|---|
| 1 | 「通知」と「CEO ACTION REQUIRED」に同じ項目が重複 | **ACTION REQUIRED に一本化**。通知（FYI）はベルのドロップダウンへ | 判断すべきものが一目で分かる |
| 2 | ACTION REQUIRED が右列の中段 | **右列最上段・常時表示・赤のグロー枠・件数大表示**。その場で［承認］［差し戻し］ | 最重要エリア |
| 3 | ヒーロー画像が大きい | 高さを約 2/3 に圧縮し、**Morning Briefing の3行要約**を表示 | 雰囲気を保ちつつ情報化 |
| 4 | KPIカードは数値のみ | 前日比・ミニスパークライン・クリックで詳細 | 変化が分かる |
| 5 | AI社員カードは静的 | **presence をリアルタイム反映**（脈動ドット・作業ラベルの切替アニメ）。`blocked`/`承認待ち` を先頭にソート | 「働いている」感 + 異常に気づく |
| 6 | 会社全体の進捗が小さい | KPI行の右端で維持（リング + 7日推移） | |
| 7 | 下段が4カラムで窮屈 | 3カラム（PJ進捗 / 最新レポート / 会話ログ）+ 右列に今日の予定 | 可読性 |
| 8 | Command Center が下部のみ | 下部の常設バー + **⌘K でどこからでも起動**。入力後は COO の受付→計画が流れるように表示 | 指示を出す体験の強化 |
| 9 | — | ヘッダーに **LLM残り枠 / Worker稼働状態 / Kill Switch** | 運用の安心感 |

### グリッド

- 全体: サイドバー 220px（1600px未満で 72px アイコンのみ）+ メイン 12カラム（gap 16px）+ 右列 360px 固定。
- 行の高さ配分（1080px）: ヘッダー 56 / ヒーロー 150 / KPI 110 / Workforce+Performance 300 / 下段 250 / Command 80 + 余白。
- 各パネル内は**内部スクロール禁止**を原則とし、件数上限で切る（"すべて見る"へ）。例外: 会話ログのみ自動スクロール。

### レスポンシブ

| 幅 | 方針 |
|---|---|
| ≥1920 | 上図そのまま |
| 1440–1919 | サイドバーをアイコン化、Workforce 4×2 → カード縮小 |
| 768–1439（タブレット） | 2カラム。ACTION REQUIRED を最上段に移動 |
| <768（スマホ / PWA） | **ACTION REQUIRED → KPI → Workforce** の縦積み。承認はスワイプ（右=承認・左=差し戻し、high以上は詳細必須） |

## 11.3 ビジュアルデザイントークン

| トークン | 値（案） | 用途 |
|---|---|---|
| `--bg-base` | `#070B14` | 背景 |
| `--bg-panel` | `rgba(16, 24, 40, 0.72)` + `backdrop-blur(12px)` | パネル（ガラス） |
| `--border-panel` | `rgba(120, 160, 255, 0.12)` | パネル境界 |
| `--text-primary` | `#E6ECF5` | |
| `--text-secondary` | `#8A97AD` | |
| `--accent-live` | `#22D3A6` | LIVE・稼働中 |
| `--accent-info` | `#4C8DFF` | 情報・Coding |
| `--accent-warn` | `#F5A524` | 承認待ち・medium |
| `--accent-critical` | `#FF4D5E` | ACTION REQUIRED・high/critical |
| `--accent-gold` | `#E9B872` | ブランド（ロゴ・夜明け） |
| フォント | 英: Inter / 数字: Inter Tabular / 和: Noto Sans JP | |

- 動き: presence 変化時のフェード、LIVEドットの脈動、新規承認カードのスライドイン + 枠グロー（1回のみ）。`prefers-reduced-motion` を尊重。
- アバター: AI社員ごとの統一トーンのポートレート（生成画像）。
- アクセシビリティ: 色だけに頼らず、リスクはバッジ文字（HIGH 等）も併記。コントラスト比 4.5:1 以上。

## 11.4 画面一覧（サイドバー）

| 画面 | 内容 |
|---|---|
| Home | 本ダッシュボード |
| Command | 指示履歴・進行中の Directive（COOの計画DAG・進捗・成果物） |
| AI Employees | 社員名簿・プロフィール・作業履歴・メモリ・設定 |
| Departments | 部署ごとのメンバー・タスク・成果物・KPI |
| Projects | プロジェクト一覧・詳細（タスクボード・タイムライン） |
| Tasks | 全タスク（フィルタ・ボード/リスト切替） |
| Reports | レポート一覧・PDFビューア・承認 |
| Activity | 全社活動タイムライン（activity_events） |
| Meetings | 会議記録・AI会議 |
| Knowledge | Vault 横断検索・ナレッジ閲覧 |
| Analytics | KPI推移・AI社員生産性・コスト |
| Settings | 会社設定・AI Provider・通知・API連携・Vault同期 |
