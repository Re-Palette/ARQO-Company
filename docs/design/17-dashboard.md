# 17. Dashboard 構成（v1.0）

添付デザインの世界観（ダークネイビー × 夜明けの都市 × ネオンアクセント）と情報密度を継承し、v1.0 の要件で再構成する。

## 17.1 v1.0 のレイアウト方針

| 優先 | エリア | 位置 | 役割 |
|---|---|---|---|
| 1 | **CEO ACTION REQUIRED** | **最上部・全幅** | CEOが判断しないと進まないものだけ |
| 2 | KPI Strip | 2段目 | 会社の数字（Re-Palette KPI を含む） |
| 3 | **Company Timeline** | **中央** | 会社全体の活動を時系列で |
| 4 | Live AI Workforce | 左 | AI社員が今何をしているか |
| 5 | AI社員パフォーマンス / プロジェクト / 予定 | 右 | 成果の可視化と今日の予定 |
| 6 | Command Center | 最下部（常設） | 指示を出す |

参考画像からの主な変更:

| 参考画像 | v1.0 |
|---|---|

## 17.3 各パネル仕様

### CEO ACTION REQUIRED（最上部）
- 表示対象: [12章 12.1](./12-approval-flow.md#121-ceo-action-required-の定義) の「判断待ち」のみ。
- 最大4枚を横並び（スコア順）。5件目以降は「+N件」→ 一覧ドロワー。
- 枠: `--accent-critical` のグロー（新着時に1回だけ脈動）。件数を大きく表示。
- カード内で完結: [承認]（hash 付き）/ [差し戻し]（コメント欄が展開）/ [詳細]（ドロワー）。
- **止まっているもの**（タスク数・プロジェクト）と期限カウントダウンを必ず表示。
- 0件時は緑の細いバーに縮小（「判断待ちはありません。AI社員は自律で稼働中」）。

### KPI Strip
- AI社員（総数 / 稼働中）、今日のタスク（総 / 完了 / 進行・時間別スパークライン）、プロジェクト（総 / 進行中）、判断待ち（件数 / HIGH 件数）、会社全体の進捗（リング + 7日推移）、**Re-Palette トップKPI 3つ**（クリックで事業部画面）。

### Company Timeline（中央）
- 時刻 / アクター（アバター・アイコン）/ 1行の出来事。新しいものが上。Realtime で上から差し込み。
- 文言は `timeline_templates`（データ）から生成。例:
  - `09:12 Research AI 助成金情報を発見`
  - `09:34 Marketing AI 投稿案完成`
  - `09:45 CEO 承認: Instagram投稿`
  - `10:02 COO レポート作成開始`
- アクター種別バッジ: 👤 CEO / 🧠 COO / 部署アイコン / 🤖 Universal AI / ⚙ System
- フィルタ: 全て / CEO / 判断 / 会話（社員間の会話ログ）/ 部署 / プロジェクト。
- 重要度4以上は太字、判断関連は左ボーダー色。クリックで詳細（関連タスク・成果物・判断）。
- 連続する同種イベントは折りたたみ（「CTO がファイル更新 ×5」）。
- 表示は当日分（パネル内のみ縦スクロールを許可する唯一の例外）。過去は Activity 画面。

### Live AI Workforce（左）
- 2列×4 = 8名表示。並び: `blocked` → `waiting_approval` → 稼働中 → idle。ページ送り。
- カード: アバター、名前・部署、presence（色ドット・脈動）、作業ラベル、今日のハイライト指標1つ。
- ホバー: 現在のタスク・直近の判断（Agent Memory）・今日の実績。

### 右列
1. **AI社員パフォーマンス（7日）**: 社員ごとのハイライト3指標 + トレンド矢印。部署フィルタ。クリックで社員詳細。
2. **プロジェクト**: `pinned` プロジェクトの進捗リング（最大6、データ駆動）。
3. **予定 / レポート** タブ: 今日の予定、最新レポート（承認状態・Approved バッジ）。

### Command Center（最下部常設 + ⌘K）
- 指示入力 → 送信後、Timeline に「COO 受付」「COO タスク分解」が流れて見える。
- `@プロジェクト` `#部署` の補完。クイックアクション: レポート作成 / 新規プロジェクト / タスク追加 / 会議設定。

### ヘッダー
- 挨拶 + Morning Briefing の1行要約（クリックで全文）。
- Worker 稼働状態、AI 残り枠、通知ベル（FYI）、Kill Switch（設定メニュー内）。

## 17.4 レスポンシブ

| 幅 | 方針 |
|---|---|
| ≥1920 | 上図 |
| 1440–1919 | サイドバーアイコン化、Workforce カード縮小、右列パフォーマンスを2指標に |
| 768–1439 | ACTION REQUIRED（横スクロールカード）→ KPI → Timeline → Workforce → 右列 の2カラム |
| <768（PWA） | **ACTION REQUIRED → KPI → Timeline** の縦積み。承認はスワイプ（high 以上は詳細必須） |

## 17.5 デザイントークン

| トークン | 値 | 用途 |
|---|---|---|
| `--bg-base` | `#070B14` | 背景 |
| `--bg-panel` | `rgba(16,24,40,0.72)` + blur 12px | ガラスパネル |
| `--border-panel` | `rgba(120,160,255,0.12)` | |
| `--text-primary` / `--text-secondary` | `#E6ECF5` / `#8A97AD` | |
| `--accent-live` | `#22D3A6` | LIVE・稼働中 |
| `--accent-info` | `#4C8DFF` | 情報 |
| `--accent-warn` | `#F5A524` | medium・承認待ち |
| `--accent-critical` | `#FF4D5E` | ACTION REQUIRED・high/critical |
| `--accent-gold` | `#E9B872` | ブランド |
| `--accent-repalette` | `#F2A7C3` | Re-Palette 事業部 |
| フォント | Inter（数字は tabular）/ Noto Sans JP | |

- 動き: presence 変化のフェード、Timeline の差し込みアニメ、新着判断カードのスライドイン。`prefers-reduced-motion` 尊重。
- アクセシビリティ: リスクは色 + 文字（HIGH 等）、コントラスト 4.5:1 以上。
